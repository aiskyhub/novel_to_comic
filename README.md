# novel_to_comic

将小说或长篇故事忠实改编为完整漫画的 Codex 插件与通用技能体系。

通篇剧本先行与多轮自校验，完整页提示词先打磨，一页一次生成并整页验收，按原始图片导出完整漫画。

## 核心特性

- **严格忠实与三级证据推断**：严格忠于小说原文，保留全部有效叙事细节。确立明确的三级证据边界：
  1. *原文明示事实*：严格忠实，必须具有精准出处与原文短引句；
  2. *视觉呈现选择*：允许为呈现事实所需的专业视听转译（机位、构图、中间帧动作、微表情神态），明确标明为视觉呈现（visual staging）；
  3. *新增情节/动机/因果*：绝对严厉禁止（一票否决）。
- **两层级分镜与完整页生成**：
  - *整章/整卷维度*：忠实展开细节，**整章叙事总格数不设固定硬上限**（约 2,000 字中文章节常规参考 50–80 格，密集内容按需展开），绝不为了压缩篇幅过度概括，也绝不为了凑格虚构新剧情；
  - *单张成图/单页维度*：适配手机竖屏阅读，**成品页建议 1080×2400（9:20），每页 3–5 格整宽纵排**；正文建议字高约 16 CSS 像素（360 宽视口），文字清晰易读；每页一次生成包含全部镜头与气泡的完整 PNG。详见 [手机阅读规范](references/phone-reading.md)。
- **默认复制归档保护原稿**：初始化唯一默认行为为**复制原稿到 `source_texts/` 并校验 SHA256**，完整保留外部原稿；移动文件必须由用户显式指定。
- **机械门禁与语义审查双轨制**：流水线脚本自动核验结构、哈希与文件指纹（机械门禁）；执行者与审阅人必须亲自核对原文细节、连贯性与看图品质，以具体段落和画格为证据（语义审查）。
- **环境自适应委派**：仅当宿主运行环境支持并行代理且任务可独立拆分时委派子代理；使用环境推荐模型或继承配置，主代理始终把控创作与终审。
- **规范权威单一来源**：建立规范映射体系，文档模板唯一由 `assets/templates/` 维护。

## 目录结构

```text
novel_to_comic/
├── .codex-plugin/
│   └── plugin.json                  # Codex 插件清单配置
├── SKILL.md                         # 技能主入口及指令说明
├── VERSION.json                     # 技能版本信息
├── agents/                          # 代理定义
├── assets/                          # 模板库（assets/templates/）与静态配置
├── references/                      # 架构规范、分镜标准、质量验收与权威参考
├── scripts/                         # 完整页提示词、页尝试账本、原稿提取与导出脚本
├── tests/                           # 自动化单元测试与回归套件
├── validation/                      # 测试样本与技能包校验工具
│   ├── check_skill_package.py       # 技能包完整性校验
│   └── sync_installed_skill.py      # 当前技能镜像同步、删除废弃文件
└── README.md
```

## 安装与使用

### 通过 Codex Marketplace 安装

在 Codex 中添加 aiskyhub 市场源并安装：

```bash
# 添加市场
codex plugin marketplace add aiskyhub/aiskyhub

# 安装插件
codex plugin install novel-to-comic@aiskyhub
```

### 技能调用

```text
$novel-to-comic 将我提供的小说忠实改编为完整漫画。
```

## 测试与校验

运行单元测试套件：

```bash
python -B -m unittest discover -s tests -v
```

运行技能包格式与引用校验：

```bash
python validation/check_skill_package.py
```
