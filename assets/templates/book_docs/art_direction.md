# 《{{book_title}}》全书美术规范与视觉基准

## 1. 统一主画风

- **风格定位**：精致优雅、细致清晰线条、清透协调配色。
- **线条规范**：轮廓线干净稳定，内线轻盈，避免多余粗糙线头与非叙事杂乱排线。
- **上色与明暗**：克制清透的主要明暗层次，暗面色相干净，保留表情和关键动作可读性；避免全图脏黄滤镜。
- **背景与空间**：形块清晰交代空间关系，有组织留白；人物对白与重要冲突时适度概括，减少杂物堆砌。

## 2. 版式与画格节奏

- **默认格式**：固定页漫 / 条漫
- **画布尺寸**：建议 1080 × 2400（9:20 竖屏，高宽比建议 2.0–2.4）
- **手机正文**：建议 48–60 像素（360 宽视口建议约 16 CSS 像素），清晰易读
- **版面**：单页限定 2–3 格整宽纵排，画面自然饱满
- **构图动线**：每格具备清晰视觉中心；全部画格整宽纵排，按关键动作、对话和情绪调整格高。
