# 单页完整漫画提示词打磨模板

只输出一张完整竖屏漫画PNG。一次绘制整页全部内容。

画幅：1080×2400，9:20（建议竖屏基准），按手机宽度显示占约一屏。页内共〔实际格数，严格限定2到3格〕格，从上到下整宽纵排；给出各格高度主次、窄边距与格距，漫画内容布局自然饱满。

画风与参考：〔具体线条、配色、光照和背景详略〕。〔每张参考对应的人物/形态/用途；身份锚点与当前服装状态〕。

逐格叙事：按锁定稿真实顺序逐个填写，每格仅一个动作时刻。
- 位置与高度：〔位于页内哪里，为什么强调或停顿〕。
- 镜头与构图：〔景别、角度、焦点、人物站位/朝向/视线和空间关系〕。
- 本格事实：〔原著动作、表情、关键道具、服装/伤势/持有物状态〕。
- 原样文字：〔所属气泡类型、说话人、准确台词与阅读顺序〕；旁白无尾巴，对话尾巴指向正确的人物，气泡不挡脸。

排字：1080宽成品图正文建议字高 48–60 像素（360宽手机预览建议约 16 CSS 像素），文字清晰易读、自然换行、内边距充足；纯画面格不添加任何文字。

页内连续性与终检：〔各格人物身份、当前状态、动作方向与气泡顺序是否一致〕。不要额外画格、重复镜头、跨格融合、随机文字、水印、角色/画格ID或技术标签；不新增原著情节。所有镜头与气泡直接画在这一张完整页上。

使用时把模板改成本页的具体指令，通读一次消除冲突；不得把括号占位内容发给绘图工具。生成前核对锁定稿全部台词都出现在最终提示词中。
