## 1. 人物设计总原则

- **严格忠于原著人设**：人物背景、性格、动机与人际关系必须 100% 严格基于小说原文事实，绝对禁止胡乱脑补私设。
- **男女造型清晰**：女性角色保持明确女性造型特征；男性角色保持明确男性骨相体格；不因英气或职业而模糊性别外观。
- **设计层级**：男女主角为 lead，核心配角为 core，路人为 background；主角精雕五官轮廓与体态。
- **跨卷复用**：后续卷制作时，直接引用前卷已通过的基准图与设定档案（`art/references/` 与 `design/`）。
