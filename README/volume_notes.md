- **严格忠于原著**：本卷所有情节、人物行动与对白必须 100% 忠实于小说原文，绝不胡编乱造。
- **完整细节改编**：在当前状态目录的 `docs/adaptation/` 按章保存原文细节清单与分镜映射；保留事件过程、对白交锋、心理/情绪转折与伏笔，不能用章摘要替代。格数由内容决定，不为减少生成次数删剧情。
