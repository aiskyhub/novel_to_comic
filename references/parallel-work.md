# 整页任务委派

仅在宿主支持且已有委派授权时拆分独立任务；没有授权或并发能力就顺序执行。主代理负责原文阅读、剧本、审美、完整页提示词打磨与所有终审。

绘图任务的最小单位是一张完整漫画页。每个任务包含真实page ID、锁定稿本页所有镜头和台词、主代理打磨好的完整提示词、实际参考路径与用途、页输入指纹、已登记尝试号、专属输出目录和停止条件。一次任务调用一次绘图工具并只返回一张完整PNG，不输出单独镜头资产，不混入其他页。

begin-page与finish/fail由主代理串行登记；不同完整页可独立处理，但不得共享page ID或替代pending任务。子代理只执行指定调用或机械记录，不能自行扩展生成、出备选图、写通过报告或重试直到满意。默认继承宿主模型配置，不硬编码专有模型。

主代理亲自查看整页原图与手机预览，在一份整页报告中核对全部镜头、人物与文字后完成验收。任务失败只返修对应完整页，保持尝试预算与其他已验收页。
