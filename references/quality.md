# 分阶段质量验收与双轨质检体系

质量保障实行**机械门禁**与**人工语义/视觉审查**双轨分离机制：

- **机械门禁（Automated Gate）**：由流水线脚本执行结构、类型、字段、SHA256 指纹、底层调用链溯源及状态一致性校验。能有效阻止格式缺失、哈希不匹配、版本漂移、脚本伪造等机械错误，但**绝不能证明模型实际精读了原文、未遗漏剧情或认真核验了画面**。机械通过仅为放行的必要前置条件。
- **人工语义与视觉审查（Semantic & Visual Review）**：由专业审评与品控子代理在隔离上下文中执行，主代理把关验收。必须提供可复核的实质性证据（指向具体原文段落、画格 ID、角色对比基准和修改记录），对忠实度、因果逻辑、镜头节奏和画面美感做出实质性判定。严禁以“程序已通过”或空泛词句（如“覆盖率 100%”）替代审查。

所有审查严格对照**三级证据体系**：
1. **第一类（明示事实）**：核对真实出处与剧情覆盖，严禁因过度概括而遗漏有效细节；
2. **第二类（视觉呈现）**：核对分镜机位、构图、神态与氛围是否贴合原著基调，标明为视觉呈现（visual staging）；
3. **第三类（新增虚构）**：严厉查杀自创新情节、自立动机、魔改因果与虚假台词，一票否决。

全卷实质性最终审查由终审编辑子代理执行，最终全卷验收由主代理亲自签署闭环。在剧本创作阶段，改编编剧师子代理承担逐章分镜创作职责，两名审评子代理承担每五章阶段审批的客观打分与挑刺找茬职责；剧本改稿整改师子代理专职落实驳回剧本的画格级修改；主代理作为总导演，严禁下场干具体活，负责统筹调度流程、客观裁定问题并运行 CLI 门禁校验。

## 阶段剧本质量关卡：每五章双子代理严苛审批（杜绝“一把过”与审查失真）

### 1. 实事求是审查原则（独立核查与真实闭环）

长篇小说转漫画编剧过程中，审查必须实事求是，以原著事实与视听表达质量为唯一准绳：
- **客观独立核查**：审阅人不预设必须通过或必须驳回的预定结论，不硬性规定问题数量配额与固定得分区间。重大缺陷决定是否阻断，分数用于辅助比较；
- **允许充分核查后直接通过**：若审阅人充分通读原著与分镜、核验三级证据，确认全部关键情节、高潮推进与对白风格均已准确还原且无表达缺陷，允许评定高分并签署 PASSED 直接放行；
- **发现缺陷严格据实驳回**：若存在场景建立不足、高潮动作跳步、原著笑点遗漏或对白失真，必须客观据实扣分并绑定小说真实短引句，出具 `REJECTED_FOR_REVISION`；
- **权责物理隔离与严禁代笔**：主代理定位于总导演与协调统筹，严禁肉身下场写长篇剧本，严禁亲自改剧本（防上下文混乱）；编剧由改编编剧师子代理执行，驳回由剧本改稿整改师子代理执行；审评阶段独立下发任务给两名审评子代理，严禁主代理自行编造或代替子代理填写评语，严禁批量合成伪造假报告。

### 2. 双轮打磨闭环流程（Dual-Round Workflow）

阶段审批严格执行“客观初审 → 真实整改（若有缺陷） → 复审核销放行”闭环：

1. **第一轮：独立客观初审与证据核验（Round 1: Initial Audit）**：
   - 主代理开启 2 个独立的审评子代理（主代理自主决定合适模型），通读该 5 章原文与分镜草稿，基准分 100 分，按照四大维度客观核查；
   - 挑出的每一个问题（Issues）必须客观、合理，严格绑定章节 ID（`chapter_id`）、小说原文具体短引句（`source_quote`，严禁使用模板占位符，门禁校验正文存在性）、具体画格缺陷及明确整改建议；
   - 若发现重大缺陷，初审结论为 `REJECTED_FOR_REVISION`；若经充分核对未发现缺陷，结论为 `PASSED`（直接通过进入下一阶段）。
2. **打磨整改期（Revision Phase）**：
   - 主代理集中审阅扣分清单，支持对误报问题进行客观裁定排除（须在 `adjudications` 中记录明确理由）；
   - 对有效缺陷下发整改任务单，**由剧本改稿整改师子代理（subagent_reviser）亲自修改打磨对应章节的剧本与逐格分镜，严禁主代理亲自改剧本**；并在阶段报告中记录画格级修改证据（`modified_panels`、修改前状态 `before_revision` vs 修改后具体补充 `after_revision`，且前后必须存在真实差异）；
3. **第二轮：复审核销与放行（Round 2: Recheck & Final Approval）**：
   - 两个审评子代理对照修改后的剧本分镜进行逐项核验；
   - 确认缺陷已彻底修复（或已合理裁定排除）后核销问题并重新评定最终得分；
   - 当且仅当双子代理最终复审得分均达到合格线（均 ≥85 分）、所有阻塞缺陷彻底核销（`unresolved_issue_refs` 为空）且记录完备时间戳时，方可通过该阶段。阶段报告模板见 `assets/stage-review-template.json`，并通过 `check-stage-review` 校验。

### 3. 阶梯式负向扣分量表（Deduction Rubric）

四大维度（各 25 分，基准扣分制）：

1. **关键场景描述还原度（满分 25 分）**：
   - 重要场景缺少建立镜头（Establishing Shot）或环境沦为虚空背景板：**每处扣 4–6 分**；
   - 原文明确描绘的空间纵深、光影冷暖、特殊天气（暴雨/浓雾/烈日）被忽略：**每处扣 3–5 分**；
   - 关键道具、建筑陈设或环境互动被一笔带过：**每处扣 2–4 分**。
2. **关键剧情点与高潮推进完整度（满分 25 分）**：
   - 核心矛盾、冲突升级、高潮爆发跳步（用一格或摘要粗暴交代结果）：**每处扣 5–8 分**；
   - 角色关键抉择、心理博弈与知情信息差揭示未给足镜头展开：**每处扣 4–6 分**；
   - 动作与事件前置因果铺垫（Setup）或后效反应（Aftermath）断层：**每处扣 3–5 分**。
3. **笑点与幽默包袱还原度（满分 25 分）**：
   - 原著明确的喜剧包袱、趣味梗、名场面被遗漏或被正剧化过滤：**每处扣 4–6 分**；
   - 角色吃瘪、反差萌、神吐槽被平铺直叙化，缺乏颜艺/微表情特写或节奏停顿：**每处扣 3–5 分**；
   - 幽默互动节奏混乱、对白笑点未形成视觉反差包袱（Punchline）：**每处扣 2–4 分**。
4. **角色性格与台词生动度（满分 25 分）**：
   - 台词脱离原著性格，出现 AI 式书面语、陈词滥调或说教感：**每处扣 3–5 分**；
   - 角色缺少微表情、肢体语言描写，人物状态呆滞扁平：**每处扣 2–4 分**；
   - 大段旁白喧宾夺主，剥夺了角色本应有的对白或眼神交锋：**每处扣 3–4 分**。

## 全卷剧本终审（三轮自校验）

按 [narrative-density.md](narrative-density.md) 对照原文、逐章细节清单与具体分镜内容，检查清单本身是否遗漏，事件过程、关键场景描写、幽默笑点、对白交锋、心理/情绪转折和伏笔是否真实呈现。段落 ID 覆盖齐全、章摘要正确或格数达到估算范围均不能证明剧情完整。过度概括、遗漏有叙事作用的细节或关键笑点，按 major/critical 处理，修复前不得通过 coverage 或锁定；报告 evidence 必须能定位具体来源、清单项、画格、合并理由和复查结果。

每章推进到下一章前，由改编编剧师子代理在独立上下文中核查该章完整原文、逐场详细剧本和逐格分镜草稿，主代理运行 `check-adaptation` 执行校验，保存对应草稿版本、发现、修复和章末状态。约 2,000 字普通章节的 50–80 格/约 60 格只作规模参考；低于所选范围时须说明是否因实际事件少，并重查重要过程，不能仅因格数够多就通过。最终本卷审查须针对汇总后的同一最新完整稿重新确认，各章工作记录不能替代本卷最终报告。

- **coverage（覆盖度与零虚构）**：检查全部正文和结束位置，**确认无任何脱离原文的虚构画格、自创情节或私增戏码**（第三类证据违规一票否决），核对关键场景氛围、核心剧情高潮及原著笑点无遗漏；
- **continuity（因果连续性）**：沿时间与因果轨迹检查身份、装备、伤势、能力、知情和揭示，**确认所有因果转折严格来源于原著，严禁自设因果**；
- **comic（漫画视听表达）**：检查镜头可绘制性、对白归属、阅读动线、景别变化、节奏及文字密度，**确认台词对白与内心独白忠于原著语义，严禁捏造台词**；核查第二类“视觉呈现”合理自然。

报告包含 script_hash、全部正文章节 ID、checks、evidence 和 issues。凡发现任何胡编乱造、脱离原文的情节或脑补台词，直接判定为 Critical 阻断性缺陷，未解决前绝对不得出具通过报告，严禁锁定剧本。

## 人物参考

`identity`：头身、面部结构和原作身份准确。
`distinctiveness`：容易混淆的角色经去名/相近衣服/弱化颜色比较仍可辨认，或符合原文要求的相似性。
`angles_and_expressions`：常用角度、表情和比例一致。
`source_faithfulness`：原作事实与自由美术设计清楚区分，服从原作。

`gender_readability`：女性造型清晰，男性造型清晰；英气/强势女性仍保持女性面部与体态。原作规定的特殊表达须查实来源。
`body_design`：肩颈、头身、身体比例、姿态与个人轮廓协调，符合年龄与人设。
`design_tier_fit`：男女主角五官、体态、表情与服饰完成度精致，重要配角有独立设计，路人结构正确并保持合理细节层级。

参考报告必须含 reviewed_ids、comparisons、findings；comparisons 记录实际比较的角色与面部、体态、表现差异。findings 保存缺陷、严重度、处理和复查结果；没有缺陷时用空数组。不要用自动人脸阈值代替美术子代理或人工审图。

图像报告的 `image_sha256` 对应本次真正查看的文件内容；相同人物 ID 不代表可以给另一张图复用旧报告。参考报告另用 `reference_visual_key` 绑定当前设计与参考语义，完整页报告用 `attempt_binding` 绑定实际尝试与视觉输入。机械字段通过 `qa-inputs` 读取，格式见 [schemas.md](schemas.md)。原图、参考或输入发生变化后重新看图和记录；每次报告与尝试保留历史，新增通过结论只能来自明确检查。

参考、正文与页面均检查 `visual_elegance`。报告必须有 `elegance_notes`，逐项记录 `linework`（轮廓与内线、杂乱刻线或纹理）、`color_and_light`（肤色、暗面、配色与光源）、`visual_hierarchy`（视觉中心、背景简化与留白；页面另看疏密和文字层级）的实际观察。遵循已冻结题材风格；清透不是把夜景一律提亮，简洁也不是省略关键表情或道具。用户指出画面脏时，先定位具体纹理、杂物、色偏或层次问题再修图，未重绘复查的旧图不能换成通过结论。

## 正文画格

`identity`：各人身份与对应区域清楚，未融合或换脸。
`continuity`：形态、服装、伤势、持有物、位置、能力与上一状态吻合。
`composition`：动作时刻、景别、空间、阅读和信息揭示正确；主要视觉中心清楚，前中后景、留白和文字预留区符合本格用途。
`drawing_quality`：结构、手肢、道具、背景和线条达到锁定画风的要求；与项目 art_direction 和基准图比较造型、明暗、配色、背景详略和特效。
`no_unwanted_text`：画面无错误对白、随机字符、画格 ID 标签或水印。

`native_detail`：由画面与排版品控员子代理查看完整原生页及手机阅读尺寸，逐个核对页内全部镜头的人物五官、线条、手肢、动作和道具，与人物基准比较；detail_notes记录具体位置和观察。画幅/像素通过不等于画质通过，整页好看也不能掩盖某个镜头缺失、重复、错脸或文字不可读。全部检查记入同一份整页报告，不生成独立镜头文件。

正文同时检查 gender_readability、distinctiveness、body_design、design_tier_fit。整页报告的reviewed_ids按页内叙事顺序列全实际分镜ID，findings 保存本次发现；角色换角度、换表情、换装后仍可辨，主角保持精致，女性不无依据中性化，人物不向通用脸漂移。引用真实参考 ID 与形态版本说明比较结果。

## 成品页面

按 [phone-reading.md](phone-reading.md) 查看 360/390/430 CSS 像素宽成品预览。`phone_readability` 核对画面自然、正文清晰易读（360 宽视口建议字高约 16 CSS 像素）；`phone_reading_notes` 逐页记录页 ID、三种预览宽度、实测最小正文显示字高与阅读观察。

`text_accuracy`：每句话与锁定稿相符，无错字、漏字、裁切、缺字或溢出。
`reading_order`：镜头、文字和章节顺序正确；整页缩略图的重点、分格疏密、页边距和气泡层级清楚，正常阅读尺寸的文字可读。
`speaker_assignment`：说话人、思想与旁白归属清楚，气泡/标签没有错指。
`face_visibility`：脸部、动作、关键物和剧情信息可读。

## 最终完整性
 
`source_scope`：覆盖范围和缺失情况如实记录。
`story_complete`：全部有效原文及锁定稿内容均有成品。
`docs_plot_faithfulness`：项目顶层 `README.md`、各卷 `README.md`、`docs/overview.md` 与 `docs/info.md` 中的所有剧情描述、核心看点及叙事焦点，必须逐项核对确认完全 100% 忠实于小说原文真实事件，无任何脑补、臆测或为了文案好看而编造的剧情；未读或后续卷次无任何虚假剧透或猜测。
`visual_consistency`：全书主要人物、场景与道具连续，无未处理错误；跨页/跨章的线条、造型、色彩、光影、背景质感、边框和文字语言遵循同一美术规范。回忆、夜景等变化有叙事理由和明确范围。
`exports_opened`：阅读器、PDF 和 CBZ 的实际内容经过打开或渲染验证。
 
审查失效、文件缺失/被替换、未绘画格、返修失败、存在脱离原著的虚构剧情、README/文档存在臆测编造、部分章节、只有剧本或预览图，均不得标记全书完成。小问题只有不影响阅读/忠实时才能作为明确已接受的次要说明保留。

美感检查按 [art-direction.md](art-direction.md) 比较整页缩略图、实际阅读尺寸和相邻页面。报告记录具体页/格与实际发现；“优雅”“高级”“像热门漫画”等形容词不能单独作为通过证据。
