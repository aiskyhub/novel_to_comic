# 按章递进编剧、本卷完整分镜与审查

## 阅读与来源

使用 `chapter` 获取当前章节的完整原文与来源 ID。按原文章节顺序逐章推进：读完本章，整理段内细节，写逐场详细剧本和逐格分镜，对照原文核查并保存后进入下一章；阅读记录只在实际读完该章后写入。最终阅读与分镜必须涵盖本卷全部正文，不要求先把整卷压成摘要后才开始编写。长章按场景分批保存，不把整本内容挤入单条提示。

序言、番外、书信、嵌入式回忆或世界说明按其叙事作用处理，不能因不属于编号章节而遗漏。章标题/出版说明可记录为附属文字。提取产生的空章和缺页必须单独说明。

每个原文正文单元必须关联画格，或给出明确的 context/repetition/paratext 处理。一个段落若含多个独立事件、对白意义或心理/情绪转折，应拆出细节并对应具体镜头内容；“已映射一格”不是完整保留的证明。按 [narrative-density.md](narrative-density.md) 保存逐章细节清单及映射，编剧和审查时重新对照原文，不能只凭章摘要。

章节草稿同时包含 [detail-records.md](detail-records.md) 定义的 `chapter_adaptations`：原文短引句、独立事实、叙事作用、实际分镜摘句、逐段重读记录及章节文档指纹。完成本章时执行 `check-adaptation --chapter ID --file scripts/chapters/ID.json`；结构通过后仍亲自完成语义核查，修复遗漏再进入下一章。本卷 `check-script`、审查、锁定与出图关卡均复核这些记录；仅旧式来源全覆盖的稿件不能放行。

## 原著忠实度与改编推断边界（Fidelity & Three-Tier Evidence Model）

**所有漫画剧情主线、因果链条、对白含义以及工程文档中的剧情概括，必须严格忠于小说原著文本，绝对禁止胡编乱造！** 为平衡忠实原著与漫画视听语言的媒介特征，改编与审查严格遵循**三级证据体系**：

1. **第一类：原文明示事实（Explicit Canonical Facts）——【严格忠实，必须有明确出处】**：
   - **范畴**：剧情事件走向、对白核心意义、角色发言态度、既定身份与人际关系、因果动机、情节揭示、原文明示的场景环境与关键道具。
   - **要求**：必须 100% 忠实原著，具备真实 `source_unit_ids` 绑定与精准原文短引句；严禁遗漏具有叙事作用的有效事实，严禁篡改因果链条与结局走向。
2. **第二类：视觉呈现选择（Visual Staging Choice）——【允许专业转译，标明视觉呈现】**：
   - **范畴**：为在画格中具象化呈现第一类事实所需的分镜机位（特写/中景/全景/俯仰视）、构图透视、分格节奏、肢体动作中间过渡、微表情神态、符合世界观的光影与环境细节。
   - **要求**：属于漫画转译的合理艺术推断。在分镜与文档中明确标明为“视觉呈现（visual staging）”。无需强行伪造原文字句出处，但必须服从角色性格基调、情节氛围与美术规范，严禁反客为主或改变情节走向。
3. **第三类：新增实体/情节/因果（Fabricated Canonical Elements）——【绝对禁止，一票否决】**：
   - **范畴**：小说中完全未发生的新事件、凭空捏造的感情线或平行冲突、改变故事走向的自创动机、与原作设定冲突的魔改剧情、无中生有的虚假对白。
   - **要求**：绝对严厉禁止。一旦发现，判定为 Major/Critical 缺陷，一票否决，剧本绝不得锁定，项目绝不得放行出图。

### README 与工程文档剧情描述零臆测
- 项目顶层 `README.md` 的分卷看板“核心剧情看点”、`docs/overview.md` 的“故事梗概”、`docs/info.md` 的“本卷叙事焦点”、看板注记等，所呈现的剧情总结必须 100% 摘自已实际阅读并确认的原文真实事件，严禁为了文案华丽或噱头而夸大编造。
- 尚未提供原文或尚未阅读制作的后续分卷，严禁根据猜测或网络同名作品记忆编造剧情，统一如实标注“待后续原文输入后提取真实剧情”。

## 编剧要求与两层级分镜规划

本卷结构、事件表、因果、人物弧线与伏笔表随真实章节阅读逐步完善；每章依次完成细节清单、逐场详细剧情剧本、逐格分镜和章末状态交接，不把剧情剧本缩成事件标题或结果摘要。

- **整章/整卷层面（总规模无硬上限）**：完整改编细节，**整章叙事总格数不设固定硬上限**。约 2,000 字常规章节参考 50–80 格、先按约 60 格估算，动作或交锋密集时 80–120 格或更多，事件较少时 30–50 格；绝不为了固定格数硬上限削减原文细节，也绝不为了凑格虚构新剧情。
- **单张成图/单页层面（3–5 格紧凑规划）**：普通成品页和一次整页绘图每张规划 3–5 格（默认3格整宽纵排，重点页1–3格；画幅与字高遵守 [phone-reading.md](phone-reading.md)，提示词打磨完整后一次生成整页），超过5格在剧本中延续下一完整页。整章总格数与单页/单批容量分别独立规划。

每格保留：原文 ID、事件 ID、章节、场景、出场人物、镜头、空间、单个可表现动作、表情、对白/旁白/音效、前后状态。多格呈现连续动作、反应和转折。建立场景时提供环境定位与关键空间关系。第一类事实直接回溯至原文，第二类视觉呈现明确标明。

心理活动优先转化为符合原著描写的行为和反应；需要精确传递的判断依据、犹豫与决策保留独白，严禁生造原著未有的心理旁白。对白仅可合并没有新增叙事作用的冗余口头重复，保留信息、语气、角色声音、交锋过程和关系变化；不能把多轮对话变成结果旁白。误导、悬念、幽默及情绪落点依原文顺序呈现。

区分叙述者知道、读者知道、角色知道。作者在全书分析阶段掌握的后文事实不能提前进入角色台词或可见画面。梦境、回忆、伪装、幻觉、平行叙事按原作的识别与揭示时机处理。

源文有明显文字错误时只在证据充分的情况下统一；实质歧义优先保持歧义，不能悄悄选一个新剧情。姓名相似不等于同一人，同一人不同身体也不等于新增角色。

## 三类独立视角的自校验

三个视角均由主代理亲自审查。子代理只能整理原文引句、来源映射和已有内容，不能承担覆盖、连续性或漫画表达的评估，不以子代理总结代替主代理阅读全文与完整剧本。

1. **覆盖（coverage）**：按章节重读原文，逐段补查细节清单本身的遗漏，再逐项核对细节与实际分镜内容，检查动作过程、对白交锋、心理/情绪转折、支线、成长、关系、能力变化、伏笔回收与真实收尾。核查合并和 context/repetition/paratext 项，确认没有隐藏新增叙事信息。**遗漏有叙事作用的细节或用结果摘要跳过重要过程，按 major/critical 阻断处理；反向核查自创情节、虚构画格或私加戏码，确保零遗漏、零捏造**。
2. **连续性（continuity）**：沿时间、因果与角色轨迹重读剧本。检查身份、位置、装备、伤势、能力限度、动机、状态转换和知情范围。**核对每一个重要因果变化均有原文绝对支持，严禁自创因果逻辑与动机**。
3. **漫画表达（comic）**：只读可绘制剧本，检查每格是否清楚可表现、动作是否连续、空间是否能读懂、对白是否指向正确人物，篇幅与文字密度是否适合所选版式。**核对台词、独白与旁白忠于原著文字与原意，严禁捏造台词或自创解说**。

每轮记录实际检查的章节、发现、修订和证据。发现 major/critical 问题（尤其是任何虚构或脑补情节）必须彻底剔除并重查。稿件变化后重做受影响的内容，并在全书层面核对三个报告均针对最新完整版本。不得只更换旧报告的 hash。

`check-script` 无错误后才提交审查报告；三类报告均真实通过且确认无任何胡编乱造后执行 `lock-script`。脚本的三类报告要求是行为约束，不代表三名独立评审者或自动语义判别。

## 页面叙事与长篇上下文

每页填写 narrative：purpose、new_information、emotion、focus_panel_id、page_turn。重点与翻页服务原文信息与情绪，收尾可明确写结束而无需新增悬念。按需使用 script-chapter 读取章节及相关档案，用 set-script-chapter 合并受影响章节，impact 检查修改范围；最终仍做通篇结构、覆盖、连续性和漫画表达审查。测试样例的人物与故事只用于验证，不带入用户作品。
