# 整页漫画一次生成与整页验收

正文唯一制作方式：一页对应一个完整提示词、一次绘图调用、一张完整成品PNG。单页漫画限定为 2–3 格，是同一图片里的叙事布局，绝不是多个独立生图任务。禁止分格生图、拆图、裁切画格、跨页合图、后续拼格和代码补气泡；没有这些流程的兼容入口。

## 提示词先打磨，再消耗绘图额度

必须先读 [phone-reading.md](phone-reading.md)，完成本卷详细剧本与审查锁定、人物基准登记，再为每个真实page ID编写提示词。

1. 以锁定稿为唯一剧情输入，核对本页全部panel_ids、事件、镜头、人物状态与原文台词。单页严格限定 2–3 格整宽纵排（默认 3 格，重点画面允许 2 格）；文字多或镜头多时在编剧阶段增页，保持完整剧情，不靠缩字或加格压篇幅。
2. 使用 `build-prompt --page 页面ID --notes 本页美术排版笔记 --output 提示词文件` 生成完整页提示词。notes写本页具体视觉中心、格高、气泡位置、背景取舍、相邻镜头过渡和人物辨识，不写泛泛的“高清”“精美”，不增加原著事件。
3. 主代理亲自通读并打磨最终提示词：画幅与格数只声明一套；各格位置、动作时刻、角色站位、视线与道具状态相互一致；逐句核对原样台词、气泡归属和顺序，给文字留够可读空间。把不必要背景细节从提示词中删掉，把剧情必需信息保留。
4. 检查人物参考的真实文件与用途：只带本页实际人物/形态、场景和道具，避免未来装备或参考标签进入正文。自动选择已验收且覆盖当前角色/形态的参考；需要指定时在page.reference_ids中明确登记ID后重审。不能因参考少而把人物改成通用脸。
5. 提示词就绪才 `begin-page --page ID --prompt 完整提示词`。如果已验收返回generation_required=false，直接复用整页；pending则恢复同一次任务。否则使用返回的实际提示词和参考路径 **调用一次绘图工具，只请求一张完整页**。

完整提示词的组织模板见 [page-prompt-template.md](../assets/page-prompt-template.md)。该模板是打磨清单，不能机械填空后声称已完成构图审查。

## 完整页提示词的必需内容

- 明确输出一张完整竖屏漫画PNG，目标1080×2400、9:20；不输出变体或独立镜头文件。
- 严格给出本页格数、纵向阅读顺序与各格高低主次。边框由绘图工具在整页中一并完成，画面饱满且不靠大空白占屏。
- 统一画风、配色、光照、人物身份锚点；参考与角色/形态对应清楚，同一人物在页内所有格保持一致。
- 每格给出一个动作时刻、景别、空间、人物位置和朝向、表情、关键道具及当前服装/伤势/持有物状态，不把多个连续动作塞进一格。
- 每句对白、独白、旁白按锁定稿逐字列出，标明所属格、说话人、气泡类型和阅读顺序。指定尾巴只指向说话人，旁白无尾巴，气泡不挡脸与关键动作。
- 字高、内边距与行距按手机阅读标准明确请求；不要缩字容纳长对白。无字格明确禁止添加文字。
- 禁止额外镜头、重复画格、跨格融合、随机字符、角色名标签、技术参数、水印和无来源情节。

## 一份整页报告完成验收

生成后亲自查看整页原图与360/390/430宽等比预览，在同一份页面报告中逐个核对页内镜头、全部台词、角色一致性、画面细节、气泡归属和阅读动线。**在整页里检查所有画格，不裁出独立图片，不另开逐格生成或验收任务。**

执行 `qa-inputs --page ID --attempt 次数 --file 整页PNG` 获取真实图像哈希和attempt_binding；该命令只返回机械绑定，不生成通过报告。填写PAGE_ART_CHECKS及真实观察、reviewed_ids（本页全部分镜ID）、reviewed_page_ids、phone_reading_notes后 `finish-page`。文件按原始字节归档到art/pages，不能修改或压缩到低质量再交付。

画布尺寸是请求目标，工具实际输出可能有小幅差异：保留真实原生PNG，高/宽建议 2.0–2.4（容差 1.6–2.6 兼容主流竖屏），宽至少 800 像素；最终按实际宽度核查字高。目标 1080×2400 不能当作工具已保证输出的证据，不拉伸、裁切、补边或放大去伪造尺寸。

整页存在严重缺陷（如严重错脸、文字乱码、剧情脱离原著）时记录 `fail-page`；改进提示词返修完整页。每个有效页输入最多三次实际调用，达到上限后推进其他独立页。

## 成品归档与导出

`prepare-pages`只按顺序复制已验收的整页原始PNG，生成向下缩放的手机预览并登记哈希；它不生成或组装漫画内容。完成全页阅读检查后review-layout，再export导出离线HTML、PDF、CBZ并verify-export。实际打开阅读器和导出文件，确认全文顺序与可读性后complete。
